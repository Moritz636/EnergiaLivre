# Prompts para Gerar Imagens no Grok

## Especificações Técnicas
- **Formato**: WebP
- **Proporção**: 16:9 para banners, 1:1 para avatares/testimonials
- **Dimensões em mm**:
  - Banners (header/hero): 1920x1080px (~508x286mm a 96dpi)
  - Cards/testimonials: 400x400px (~106x106mm a 96dpi)
  - Ícones/ilustrações: 200x200px (~53x53mm a 96dpi)

## Prompt 1: Mariana R. (Depoimento de Parceira)
```
Gere uma foto profissional estilo LinkedIn de uma mulher brasileira, 35 anos, sorridente, 
aparência confiante, vestindo roupa casual-chique (blazer claro), fundo desfocado com 
painéis solares ao fundo. Iluminação natural. Estilo fotografia corporativa moderna. 
Proporção 1:1, 400x400px. Banco de imagens realista, não ilustração.
```

## Prompt 2: Rafael C. (Depoimento de Parceiro)
```
Gere uma foto profissional estilo LinkedIn de um homem brasileiro, 40 anos, barba por fazer, 
sorrindo, vestindo camisa social azul clara manga longa, fundo com grama verde e céu limpo 
com painéis solares ao fundo. Iluminação natural dourada. Estilo fotografia corporativa 
moderna brasileira. Proporção 1:1, 400x400px. Banco de imagens realista, não ilustração.
```

## Prompt 3: Juliana L. (Depoimento de Parceira)
```
Gere uma foto profissional estilo LinkedIn de uma mulher brasileira, 28 anos, cabelos 
cacheados, sorriso natural, usando blusa branca, fundo com parede de vidro e plantas 
naturais. Iluminação suave estilo happy hour. Estilo fotografia corporativa descontraída. 
Proporção 1:1, 400x400px. Banco de imagens realista, não ilustração.
```

## Prompt 4: Hero Banner - Parceiros (1920x1080px)
```
Crie uma imagem 16:9 de uma equipe diversa de brasileiros felizes em um campo aberto com 
painéis solares ao fundo, pôr do sol dourado, sensação de energia e comunidade. Estilo 
fotografia comercial de alta qualidade, cores quentes. Texto vazio, sem pessoas olhando 
diretamente para a câmera. Proporção 16:9.
```
